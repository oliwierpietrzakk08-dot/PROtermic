# PROtermic - Static Website

This is a high-end, minimalist single-page website for PROtermic, built with vanilla HTML5, CSS3, and JavaScript.

## Features
- **Minimalist Aesthetic**: Pure white background with deep black text and orange accents.
- **Single-Page Architecture**: Fast, simple, and easy to deploy.
- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop).
- **Interactive Elements**: Smooth scrolling, fade-in animations, and a filterable gallery.

## Files
- `index.html`: The main entry point containing all structure, styles, and logic.

## Deployment
Simply upload `index.html` to any static web hosting (GitHub Pages, Vercel, Netlify, etc.).
